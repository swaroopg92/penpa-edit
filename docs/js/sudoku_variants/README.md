# Sudoku Variant interpretation

This directory is the build-discovered parsing seam between Penpa puzzle data
and the CSP compatibility view.

- `descriptors/` contains one entry file per migrated variant.
- `parsers/` contains shared, pure-JavaScript parsers for cohesive input
  families. Descriptors never read Penpa drawing-layer objects directly.
- `runtime.js` owns the read-only Puzzle Evidence API, descriptor composition,
  diagnostics, and versioned Constraint Instance emission.
- `constraint_families.js` validates payloads before they reach the solver.
- `browser.js` is generated by `npm run build:csp-variants`; do not edit it by
  hand.

Batch 1 established the registry with four pilot variants. Batch 2 moved the
geometry-only/global rules and deleted their legacy parser block. Batch 3 added
normalized cell, line, edge, intersection, and directional mark evidence, then
migrated representative rules through every marked-input family. Further
variants should reuse these evidence methods and shared family parsers, add a
parity fixture, and remove their legacy selection path in the same change.

Batch 4 moved the remaining thirteen intersection/quad variants through one
shared quad parser. Batch 5 moved the remaining eleven directional-arrow
variants through one shared directional parser. Both legacy family blocks were
deleted after their compatibility views reached parity. Parser implementation
files are discovered before `*_descriptor.js` factories so the generated
browser registry has deterministic dependency order without a manual manifest.

Batch 6 moved the remaining twenty-eight catalog and diagonal edge variants
through one shared edge parser, including their negative-rule expansion.
Batch 7 moved ten cage, line, symbol, number, shading, wall, and intersection
cell variants through one shared cell parser. Puzzle Evidence now exposes cage
labels, cell shading, and normalized wall segments; the corresponding legacy
edge and cell selection paths were deleted after parity passed.
